# 固定输出格式规范

本文件规定本 skill 对外交付时的固定格式：事实核对卡、文件命名与输出目录、交付报告和 PPT 提示词模板。所有生成活动都遵守本文件；用户或通知明确指定命名、目录或输出形式时，以用户或通知为准。

## 1. 事实核对卡（生成前输出）

确认必要信息后、开始成稿前，先向用户输出一次事实核对卡。核对卡是所有交付物的统一事实源，案例、总结表、心得体会和 PPT 不得与其冲突。

```markdown
| 项目 | 内容 | 来源 |
|---|---|---|
| 活动主题 | （主题全称，含口号） | 通知/用户 |
| 活动名称 | 主题 + 主题团日活动 | 生成规则 |
| 学院（全称） | | 通知/用户 |
| 团支部（简称） | | 用户 |
| 日期口径 | 单日 2026年6月18日 或 跨天区间 | 用户 |
| 活动地点 | | 通知/用户 |
| 支部人数 / 参加人数 | 数字，或「未涉及」「待确认」 | 用户/授权生成 |
| 负责人 / 联系电话 | 仅总结表需要时填写 | 用户 |
| 文风口径 | 已开展（过去时）或 方案（拟/计划） | 用户语义 |
| 篇幅口径 | 案例 1800—2800 字 / 心得 800—1200 字 / PPT 10—12 页 | 默认或用户指定 |
| 本次交付物 | 案例docx、总结表docx、心得docx、PPT提示词md | 用户要求 |
```

- 未确认字段写「待确认」，不得虚构；字段只在本批交付物需要时才要求确认。
- 用户修改核对卡后，先更新核对卡再生成，全程保持单一事实源。
- 一次生成多种材料只输出一张核对卡；分多轮追加材料时复用并更新同一张核对卡，不重复输出全表。

## 2. 文件命名与输出目录

默认在当前工作目录新建 `团日活动材料/` 作为输出目录；用户指定目录时使用用户目录。模板副本写入输出目录，不覆盖 `assets/` 原模板。

| 交付物 | 默认文件名 |
|---|---|
| 活动案例 | `团日活动案例-{支部简称}-{YYYYMMDD}.docx` |
| 总结表 | `团日活动总结表-{支部简称}-{YYYYMMDD}.docx` |
| 心得体会 | `团日活动心得体会-{支部简称}-{YYYYMMDD}.docx` |
| PPT 提示词 | `团日活动PPT提示词-{支部简称}-{YYYYMMDD}.md` |
| PPT 文件（用户要求直接生成时） | `团日活动PPT-{支部简称}-{YYYYMMDD}.pptx` |

- `{YYYYMMDD}` 使用确认后的活动日期；日期未确认时省略该段。
- 预览版在扩展名前加 `-预览`，例如 `团日活动总结表-XX团支部-预览.docx`。
- 支部简称缺失时用学院简称，再缺失时用「团日活动」。
- 文件名不出现空格、`[待补]` 等占位符。

## 3. 交付报告（交付后输出）

每次交付文件后，输出以下固定结构的交付报告：

```markdown
## 交付清单
| 文件 | 类型 | 版式检查 |
|---|---|---|
| 团日活动案例-XX团支部-20260618.docx | 活动案例 | 已渲染检查 |
| 团日活动总结表-XX团支部-20260618.docx | 总结表 | 已渲染检查 |

## 事实核对
- 主题：……（各材料一致）
- 日期口径：……
- 地点：……
- 人数：…… / 本批材料未涉及
- 主要流程：……

## QA 结果
逐项对应 generation-spec 交付前 QA 清单，标注「通过」或「不适用」。

## 待确认事项
- 无，或列出仍缺失、需用户确认的字段。
```

- 只交付纯文本（如单一 PPT 提示词或心得体会正文）时，交付报告可以与正文合并为一段简洁说明，但事实核对五项（主题、日期口径、地点、人数、主要流程）不得省略。
- 版式检查未执行时如实注明原因，不虚构「已检查」。

## 4. PPT 提示词固定模板

PPT 提示词交付为单个 `.md` 文件，结构固定为「提示词正文 + 页面大纲」两部分：

```markdown
# {主题}主题团日活动 PPT 提示词

## 提示词正文（可直接粘贴给 ChatGPT 网页版）
请你作为高校共青团 PPT 设计师，围绕"{主题}"设计一份 {N} 页的 PPT，用于
{学院（全称）}{团支部（简称）}在 {活动日期} 开展的主题团日活动，地点为
{活动地点}。活动主要环节：{一句话流程}。风格庄重且贴合校园场景；不得出现
需要证据的数据、获奖结果或人物原话；每页给出页标题、3—5 条核心内容、
建议视觉、讲解重点和演讲备注。

## 页面大纲
### 第 1 页 封面
- 页标题：{主题}主题团日活动
- 核心内容：主题全称 / 学院支部 / 活动日期
- 建议视觉：……
- 讲解重点：……
- 演讲备注：……

### 第 2 页 通知要求与背景
……

### 第 {N} 页 结语回扣主题
……
```

- 中间页面按当前通知主题动态设计（通知要求、主题理解、活动过程、行动转化等），不机械加入通知没有的环节。
- 页数默认 10—12 页；用户指定页数时按用户要求。
- PPT 与其他材料使用事实核对卡的同一组信息。
